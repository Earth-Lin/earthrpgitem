EarthRPGItem 工作日志（版本 1.5）

一、版本更新
1. Gradle 项目版本更新为 1.5。
2. 默认配置补充弓箭伤害、EXDraw、弹射物轨迹、命中特效、弹射物音效开关。

二、耐久修复
1. 创造模式玩家使用 RPGItem 武器攻击不再消耗耐久。
2. 原版耐久附魔现在参与手动耐久结算。若物品拥有 UNBREAKING，原版耐久消耗按 1/(等级+1) 概率发生。
3. ExDur 仍不受原版耐久附魔影响，并继续优先于原版耐久消耗。

三、伤害与显示
1. 魔法伤害颜色调整为紫色。
2. 魔法暴击伤害颜色调整为深紫色。
3. 物理暴击伤害保持金色。
4. 真实伤害颜色调整为红色。
5. 新增弓箭伤害数字 🏹❤-生命值，默认浅绿色。
6. 新增弓箭暴击数字 🏹⭐❤-生命值，默认深绿色。

四、材质包通道
1. RPGItem 文本新增 custom-model-data / CustomModelData 字段。
2. 生成物品时会写入 CustomModelData，后续可通过资源包为单独物品绑定模型或贴图。

五、弓箭与弩
1. 新增 +BowDamage 属性，用于弓箭和弩弹射物命中伤害。
2. 新增 +EXDraw 属性，支持满弓后继续蓄力提高弹射物伤害。
3. 弓箭/弩弹射物支持弓箭暴击与魔法暴击，两者独立判定。
4. 弹射物命中时会破除目标无敌帧。
5. 弹射物可触发命中粒子、命中音效、弹道粒子和弹道音效。
6. 拉弓期间新增特殊音效，默认音符盒音色，音调由低到高。

六、模板物品
1. exdraw8_bow.txt：EXDraw8 测试弓，附带弹道粒子、弹道音效、命中烟花爆炸粒子和烟花爆炸音效。
2. magic_bow_sample.txt：同时拥有 BowDamage 与 MagicDamage 的测试弓。
3. magic_crossbow_sample.txt：同时拥有 MagicDamage 与打击音效的测试弩。
4. soulbound_sword_sample.txt：重新补回灵魂绑定测试剑。

七、后续建议
1. 弹射物状态目前保存在内存 Map 与 PDC 标记中，适合战斗生命周期，不建议跨重启保存。
2. 如果后续需要多种弹道形状，可在 projectile-trail-particles 增加 effect 字段并复用现有 ParticleEffectPlayer。
3. 如果要做材质包联动，建议为每个 RPGItem 分配稳定 custom-model-data 编号并写入独立登记表。

版本1.5 续写修复记录（二）

一、灵魂绑定显示修复
1. 灵魂绑定现在在物品描述底部显示玩家游戏名，例如 bind:EASFXk_SAFQW。
2. 内部仍兼容旧版本已经写入 UUID 的物品，玩家再次使用自己的旧绑定物品时会自动迁移显示为玩家游戏名。
3. 权限判断兼容 UUID 和玩家名，避免旧物品突然失效。

二、弓箭/弩弹射物伤害修复
1. 弹射物命中实体时不再依赖原版无敌帧结算，命中后会先清除 NoDamageTicks，再强制用玩家作为伤害来源造成伤害。
2. 这样其他监听玩家伤害来源的插件更容易识别为玩家造成的伤害。
3. 弹射物 RPG 伤害现在会正常生成伤害数字，包括：
   - 🏹❤-(生命值)：弓箭普通伤害，浅绿色。
   - 🏹⭐❤-(生命值)：弓箭暴击伤害，深绿色。
   - ✡❤-(生命值)：魔法伤害，紫色。
   - 🔯❤-(生命值)：魔法暴击，深紫色。

三、弹射物粒子和声音修复
1. 弹道粒子现在直接跟随弹射物当前位置生成，不再默认抬高到弹射物上方。
2. 弹射物命中实体和命中方块现在统一使用命中特效逻辑。
3. 弹道烟花飞升声音不再被 projectile-trail-sound.enabled 的全局默认值误拦截；只要全局 projectile-sounds 开启，并且单个 RPGItem 的 projectile-trail-sound.enabled 为 true，就会播放。
4. 命中爆炸新增两种样式：
   - current：原来的随机爆开样式。
   - circle / sphere / round / 圆形：从中心扩散成大圆/球面的样式。

四、弓弩近战限制
1. 玩家拿弓或弩近战攻击时，只会触发 +Attack。
2. 弓弩近战不再触发 +MagicDamage、+BowDamage、+TrueDamage、背击、刺客等远程或特殊伤害。
3. 该修复用于避免弓弩作为近战武器时错误触发魔法伤害。

五、配置兼容提醒
1. 新安装服务器会直接获得新的默认配置。
2. 已经生成过旧 plugins/EarthRPGItem/config.yml 的服务器，需要手动补充 damage-display 和 projectile-hit-particles.effect 等字段，或者备份后重新生成配置。
3. 本次没有删除旧 RPGItem 模板，新增逻辑保持向下兼容。

版本1.5 续写修复记录（三）

一、拉弓状态机修复
1. 移除了拉弓计时对 projectile-sounds 开关的依赖，即使关闭声音也会正常记录拉弓时间。
2. 普通弓在发射时根据本次拉弓力度和拉弓时长计算倍率。
3. 未拉满时不再获得 EXDraw 追加阶段，避免没拉满却打出最大伤害。

二、弩装填阶段修复
1. 接入 Paper 的 EntityLoadCrossbowEvent，在弩装填完成时保存 EXDraw 阶段。
2. 弩发射时读取装填时保存的阶段，而不是读取发射瞬间的右键状态。
3. 装填结束、切换物品、丢弃物品、退出服务器都会清理拉弓状态，避免快速拉弩后声音残留。

三、EXDraw 计算规则明确化
1. 拉满/装填完成后，每额外 1 秒增加 1 个阶段。
2. 阶段上限由 +EXDraw 决定。
3. 每阶段增加 15% 弹射物伤害，并让拉弓提示音提高一个阶段。

四、弹道声音修复
1. 弹道粒子保持每 tick 跟随弹射物。
2. 弹道声音单独使用 projectile-trail-sound.interval-ticks 控制播放间隔，默认 4 tick。
3. 单个 RPGItem 的 projectile-trail-sound.enabled 为 true 时，烟花飞升声音会随弹射物播放。

五、F 键预留
1. 新增 PlayerSwapHandItemsEvent 拦截。
2. 玩家主手或副手拿着 RPGItem 时禁止 F 键切换副手，方便后续开发 F 键武器技能。
