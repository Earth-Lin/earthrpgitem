EarthRPGItem FSkill 命令序列使用手册
====================================

一、功能说明
------------
commands 可以在一次技能释放中按顺序执行多条指令，也可以使用 delay 延迟后续指令。
每一条 delay 的数字单位是 Minecraft tick，20 tick 等于 1 秒。

二、基础格式
------------
fskill:
  commands:
    sequence:
      as-op: true
      commands:
        - "say 第一条指令"
        - "delay 60"
        - "say 三秒后执行"

as-op: true 时由控制台执行，适合 rpgitem give、broadcast 等管理指令。
as-op: false 时由玩家执行，权限和执行者身份使用玩家本身。

三、延迟规则
------------
delay 60 表示等待 60 tick，也就是 3 秒。
延迟是累计计算的。例如：

commands:
  - "say A"
  - "delay 20"
  - "say B"
  - "delay 40"
  - "say C"

A 会立即执行，B 在 1 秒后执行，C 在再等待 2 秒后执行。
多个不带 delay 的命令会在同一轮立即执行。
也支持 delay: 60 写法。

四、变量替换
------------
${player}、{player} 和 @self 都会替换成技能释放玩家的游戏 ID。
示例：

- 'command{c="rpgitem give ${player} 陨铁剑"} @self'

五、兼容 MythicMobs 风格写法
----------------------------
command{c="指令内容"} @self 会提取 c 中的指令并执行。
message{m="文本内容"} @self 会向释放技能的玩家发送消息，不会执行服务器指令。
示例：

- 'command{c="broadcast &6陨铁剑即将觉醒"} @self'
- 'message{m="&a兑换成功"} @self'

六、陨铁剑兑换书示例
--------------------
插件首次在 Weapon 文件夹生成 meteor_iron_sword_exchange_book.txt。
该物品设置 Consumables: true，使用 FSkill 后会消耗一本兑换书。
流程包含三轮全服公告，每轮间隔 60 tick，最后执行：

rpgitem give ${player} 陨铁剑

如果服务器中的目标物品 ID 不是“陨铁剑”，请编辑最后一条指令为实际 ID。
兑换流程已经排队后，玩家下线时未执行的后续步骤会自动跳过。
