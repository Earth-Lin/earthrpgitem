EarthRPGItem 饰品系统使用手册 版本2.0

一、饰品 GUI（人体布局）

玩家使用 /rpgitem accessorygui（或 /rpgitem accessory）打开饰品界面。

界面按「人体站立时佩戴饰品的位置」排布，共 10 个饰品槽：

```
列      0    1    2    3    4    5    6    7    8
行1     ·   耳饰  ·    ·    ·    ·    ·   耳饰  ·     耳饰 ×2   槽 10 / 16
行2     ·    ·    ·    ·   项链  ·    ·    ·    ·     项链 ×1   槽 22
行3    手饰  ·    ·    ·   胸饰  ·    ·    ·   手饰     手饰 ×2   槽 27 / 35，胸饰 槽 31
行4     ·   戒指  ·    ·   披风  ·    ·   戒指  ·     戒指 ×2   槽 37 / 43，披风 槽 40
行5     ·    ·    ·    ·   腰饰  ·    ·    ·    ·     腰饰 ×1   槽 49
```

- 耳饰在头两侧、项链在颈、手饰在身体两侧（手臂位置）、胸饰居中、戒指在手上、披风在背后、腰饰在腰。
- 左右成对的槽严格镜像对称（列 0 与 8、列 1 与 7）。
- 各类型容量与旧版一致：戒指 / 耳饰 / 手饰各 2 格，胸饰 / 项链 / 腰饰 / 披风各 1 格。

二、白色玻璃板占位

- 空槽显示**白色玻璃板**，板子上写着该格能放的饰品类型（例如「戒指」「耳饰」）。
- 把饰品放进白色玻璃板后，**该格直接变成饰品本体**；取走后恢复成白色玻璃板。
- 白色玻璃板是占位物，**不能被拿走，也不会被存进饰品存档**。
- 其余格子是黑色玻璃板，纯装饰。

交互方式：

- 左键点击空槽（光标上拿着对应类型的饰品）：放入。
- 右键：一次只放 / 取一个。
- 左键点击已有饰品的槽（光标为空）：取出到光标。
- Shift + 点击背包里的饰品：自动放进该类型的第一个空槽。
- 数字键 / 副手交换：同样可用，但**来源物品必须先通过校验**（不是饰品或类型不符会被拒绝）。
- 拖拽（拖着一堆物品划过多格）会被整体取消——避免占位板被拖走。

三、饰品类型配置

可在 config.yml 中修改 accessory.types 显示名称。默认类型如下：

```yaml
accessory:
  types:
    ring: "戒指 Ring"
    earring: "耳饰 Earring"
    chest: "胸饰 Chest Ornament"
    hand: "手饰 Hand Ornament"
    necklace: "项链 Necklace"
    belt: "腰饰 Belt"
    cloak: "披风 Cloak"
```

显示名的取值顺序是：config 的值 → 还原后的 config 值 → 内置中文名。

**关于乱码**：旧版 config.yml 里这 7 行曾是乱码（例如 `ring: "鎴掓寚 Ring"`）。
`saveDefaultConfig()` 不会覆盖已存在的配置文件，所以升级后老服主的文件里仍是乱码。
插件现在会自动还原这种乱码（把字符串按 GBK 取回字节、再按 UTF-8 解码），
**无需手动修改配置文件**；如果乱码无法还原，会自动改用内置中文名（戒指 / 耳饰 / 胸饰 /
手饰 / 项链 / 腰饰 / 披风），界面不会出现方块字。

想彻底清掉文件里的乱码，可以把上面这段 `accessory.types` 直接抄进自己的 config.yml 再 `/rpgitem reload`。

四、饰品文本格式

饰品文件放在插件数据目录的 Accessory 文件夹内，每个饰品一个 txt 文件。

```yaml
id: test_ring_attack
material: EMERALD
display-name: "&a攻击戒指样本"
accessory-type: ring
attributes:
  Attack: 3
description:
  - "&7只有放入饰品 GUI 后才会生效。"
```

accessory-type 决定它能放进哪个槽：ring / earring / chest / hand / necklace / belt / cloak。

五、属性生效规则

- 饰品可以拥有武器、防具、工具已支持的全部 RPG 属性。
- 饰品只有放在对应类型的饰品槽中才会生效。
- 饰品拿在主手、副手，或穿在原版装备栏时不会生效。
- 如果 features.accessory 设置为 false，所有饰品属性都会关闭。

六、管理员指令

```
/rpgitem accessory <玩家>          打开该玩家的饰品栏（目标必须在线）
/rpgitem accessory <玩家> list     以文本列出该玩家的饰品（离线也能看）
/rpgitem accessory <玩家> clear    清空该玩家的饰品栏
```

- 查看 / 管理**他人**需要权限 `earthrpgitem.accessory.admin`（默认 OP）。
- 查看自己（`/rpgitem accessory <自己>` 或 `accessorygui`）不需要额外权限。
- `list` 按类型分组打印，每件后面带槽号，便于核对；空栏显示「（空）」。
- `clear` 会返回移除的件数。
- 管理员编辑他人饰品时，**灵魂绑定与类型校验都按「目标玩家」判定**，不会因为「绑定不是你的」而全部非法。

七、旧存档迁移（槽位重排后）

槽位重排后槽号含义变了（旧 31 是腰饰、新 31 是胸饰；旧 22 是手饰、新 22 是项链），
所以插件**不按旧槽号搬运**，而是读取每件饰品自己声明的 accessory-type，放进该类型的槽位：

1. 先尝试原位保留：槽号与新类型本来就对得上的，原地不动。
2. 再按类型放进该类型的第一个空槽。
3. 类型无法识别、或该类型槽位已满的饰品，会**退还到玩家背包**（背包满则掉在脚下），并在后台打印告警。

迁移是幂等的：重复执行不会再次挪动。迁移只发生在玩家第一次被读取饰品栏时，无需手动操作。
**升级前建议备份 plugins/EarthRPGItem/accessories.yml。**

八、其他指令配合

- /rpgitem give 玩家ID rpgitem名字：给予玩家指定 RPGItem。
- /rpgitem puton 玩家ID rpgitem名字：如果目标是玩家且物品是饰品，会优先放入该类型的第一个空槽；
  如果是护甲，会装备到对应护甲栏；其他物品会放到主手。

九、管理员菜单

/rpgitem gui 主菜单中有 Accessory 饰品分类。已注册在 Accessory 文件夹中的饰品会显示在该分类中，
支持翻页和返回按钮。分类按钮不可被玩家拿走，点击饰品样本会复制一份到玩家背包。
