EarthRPGItem 属性详细使用手册 2.1
================================

一、2.1 属性格式
----------------
RPGItem 文本使用 YAML 格式，属性写在 attributes 节点中：

attributes:
  Attack: 8
  Dodge: 1
  Determination: 10%

带百分号和不带百分号的百分比值都可读取。例如 Determination: 10 与 Determination: 10% 都表示 10%。
物品必须放入对应目录并重载插件。饰品属性只有放入 /rpgitem accessorygui 的对应专属格子才生效。

二、Dodge 闪避
--------------
用途：玩家主动按 Shift 闪避一次即将受到的有效伤害。

attributes:
  Dodge: 1

判定规则：
1. 玩家受到伤害前 0.3 秒内按下 Shift，闪避成功并取消本次伤害。
2. Shift 按下时间距离受击超过 0.3 秒、但不超过 1 秒时，判定为时机错误，本次不闪避。
3. 1 秒内重复按下 Shift 会清除当前有效窗口，连续按键不能连续闪避。
4. 默认冷却为 1 秒。冷却期间按 Shift 不会闪避。
5. 成功后获得 1 秒抗性提升 III，并播放蓝白烟雾旋风粒子和音效。
6. 火焰、岩浆、虚空、饥饿、窒息、药水、剧毒、凋零和龙息伤害不判定。
7. 闪避成功不会触发 CounterAttack 反击。

三、Block 格挡
--------------
用途：玩家主动按 Shift 格挡一次即将受到的有效伤害。

attributes:
  Block: 1
  CounterAttack: 80
  CAD: 50%

格挡使用与闪避相同的 0.3 秒成功窗口、1 秒重复按键保护和默认 1 秒冷却。
成功后取消伤害、获得 1 秒抗性提升 III，并播放白色防御粒子与 0.4 音调的格挡音效。
格挡可触发 CounterAttack。弹射物伤害可以格挡，但不会对弹射物攻击者反击。
同一套有效装备同时存在 Block 和 Dodge 时，只判定 Block，Dodge 不生效。

四、Parry 招架
--------------
Parry 在旧版本手册中被称为“格挡”，2.1 起统一称为“招架”。属性键仍为 Parry，旧物品无需修改。

attributes:
  Parry: 80
  CounterAttack: 80

Parry 是受到物理或弹射物攻击时自动按概率触发的被动机制，不要求按 Shift。
招架成功继续使用原有金色粒子、全局招架音效、攻速惩罚和 CounterAttack 逻辑。

五、Determination 决意
---------------------
用途：主动闪避或主动格挡成功时，按玩家最大生命值百分比恢复生命。

attributes:
  Dodge: 1
  Determination: 20%

示例：玩家最大生命值为 40，Determination 为 20%，成功闪避后恢复 8 点生命。
治疗不会超过最大生命值。Determination 单独存在时不会触发，必须配合 Dodge 或 Block。

六、CAD 反击伤害增加
--------------------
CAD 是 Counter Attack Damage 的缩写，按百分比提高反击伤害，可超过 100%。

attributes:
  Attack: 10
  Block: 1
  CounterAttack: 100
  CAD: 150%

公式：反击伤害 = 当前有效 Attack × (1 + CAD / 100)
示例：Attack 为 10、CAD 为 150%，反击伤害为 10 × 2.5 = 25。
CAD 同时作用于 Parry 招架触发的反击与 Block 格挡触发的反击。

七、主动防御配置
----------------
config.yml：

features:
  dodge: true
  block: true
  determination: true
  cad: true

defensive-actions:
  timing-window-seconds: 0.3
  invalid-window-seconds: 1.0
  repeat-guard-seconds: 1.0
  resistance-duration-seconds: 1.0
  dodge:
    cooldown-seconds: 1.0
    particles-enabled: true
    particle-count: 48
    particle-radius: 1.0
    sound-enabled: true
    sound: ENTITY_ENDERMAN_TELEPORT
    volume: 1.0
    pitch: 1.2
  block:
    cooldown-seconds: 1.0
    particles-enabled: true
    particle-count: 48
    particle-radius: 0.8
    sound-enabled: true
    sound: BLOCK_ANVIL_LAND
    volume: 1.0
    pitch: 0.4

八、快捷丢弃保护
----------------
config.yml：

rpgitem:
  prevent-hotkey-drop: true

开启后，玩家手持 RPGItem 时按丢弃快捷键不会丢出物品。
玩家打开物品栏后，通过物品栏的丢弃操作仍可手动丢出该物品。
此项也可以在 Setting GUI 第二页切换。

九、OP 指令技能
---------------
FSkill、RSkill、LSkill 都支持 commands 节点。as-op: true 表示由服务器控制台执行，玩家本身不会被临时授予 OP。
@self 和 {player} 都会替换成技能使用者的真实游戏名称。

fskill:
  cooldown-seconds: 5
  commands:
    self_effect:
      as-op: true
      commands:
        - "effect give @self minecraft:speed 5 1 true"
        - 'title @self actionbar {"text":"技能已释放","color":"gold"}'

as-op: false 时，命令以玩家身份执行并遵循玩家自身权限。
不要在命令开头添加斜杠；即使添加，插件也会自动移除。

十、测试饰品
------------
test_dodge_ring：闪避戒指，Dodge: 1。
test_block_hand：格挡手饰，Block: 1。
test_determination_necklace：决意项链，Determination: 20%。
test_cad_earring：反击增伤耳饰，CAD: 150%。
这些饰品可以组合测试，但 Block 与 Dodge 同时存在时始终优先 Block。

2.0 已有 Attack、MagicDamage、各类护甲、比例伤害、规模伤害、元素属性等说明继续有效。
2.1 的术语修正：Parry = 招架，Block = 格挡，Dodge = 闪避。

十一、Vitality 百分比最大生命值
------------------------------
Vitality 按百分比增加玩家最大生命值，数值允许超过 100%。

attributes:
  Health: 10
  Vitality: 150%

计算公式：最终最大生命值 = (20 + Health) × (1 + Vitality / 100)
案例：Health 为 10、Vitality 为 150%，最终最大生命值为 (20 + 10) × 2.5 = 75。
只使用 Vitality: 200% 时，最大生命值为 20 × 3 = 60。

十二、普通物品英文描述属性
--------------------------
未注册为 RPGItem 的原版物品、其他插件物品可以直接通过英文描述提供属性。
支持玩家穿戴的盔甲、玩家主手物品、怪物盔甲和怪物主手物品。
普通副手物品必须额外包含 Deputy 描述才会生效，与 RPGItem 副手规则一致。

支持的格式案例：
  +Attack 5
  +Attack: 5
  +Attack <5>
  +AttackPercent 25
  +Attack 25%
  +Vitality 150%
  +Armor -2

属性名称不区分大小写。相同物品中重复出现同一种属性时会相加。
`+Attack 25%` 会识别为 AttackPercent；`+Vitality 150%` 本身就是百分比属性。

描述前可以使用颜色：
  &c+Attack 5
  §9+Armor 3
  &#FF5555+Vitality 100%
  §x§F§F§5§5§5§5+MagicDamage 8

Adventure 组件颜色、& 颜色代码、§ 颜色代码和十六进制颜色代码都会在解析前移除。
注册 RPGItem 带有专属 PDC 标识，解析器会直接跳过，因此 RPGItem 自己的描述不会再次触发属性，也不会形成双倍属性。

全局开关：
features:
  vitality: true
  lore-attributes: true

这两个开关也可以在 Setting GUI 中分页找到。

十三、护甲与伤害类型对应关系
----------------------------
Armor 只减少物理近战伤害，不减少魔法、药水、弹射物、元素、真实和环境伤害。
MagicArmor 减少 MagicDamage、魔法暴击和药水类伤害。
BowArmor 减少弓箭、弩和其他弹射物伤害；弹射物携带的魔法部分同时受 MagicArmor 与 BowArmor 影响。
IceArmor、FireArmor、LightArmor、DarkArmor 只减少对应元素伤害。
EnvArmor 优先减少全部伤害类型。
Resistance 在对应护甲结算后影响除正数 TrueDamage 外的伤害。
TrueDamage 不受任何护甲和正数 Resistance 影响。

元素百分比复制的是目标护甲结算前的武器输出，包括原版基础伤害、附加属性伤害和暴击原始伤害。
普通 Armor、MagicArmor、BowArmor、CritArmor 和原版护甲不会间接降低元素复制基数。
元素伤害最终只由对应元素护甲和 Resistance 结算。

FSkill/RSkill/LSkill 的 damages 节点当前属于物理技能伤害，因此该技能本体受 Armor 影响。
法杖物品额外拥有的 MagicDamage 是独立魔法伤害，不受 Armor 影响。

十四、给予与直接装备指令
------------------------
给予玩家物品：
/rpgitem give 玩家名 RPGItem_ID

直接装备到玩家或生物：
/rpgitem puton 目标 RPGItem_ID
/rpgitem poton 目标 RPGItem_ID

puton 是标准写法，poton 作为兼容别名保留。目标支持以下格式：
- 真实在线玩家名，例如 /rpgitem give EASFXk_SAFQW excalibur
- @self：命令执行者自身
- {player}：命令执行者自身
- <player>：命令执行者自身
- 原版选择器，例如 @a、@p、@e[type=zombie,limit=1]

give 只能选择玩家，因为物品需要加入玩家背包；puton/poton 可以选择玩家或其他生物。
如果使用命令方块或控制台执行 @self、{player}、<player>，执行者本身不是生物，因此不会获得目标。此时应填写真实玩家名或原版选择器。
错误提示会分别说明是玩家目标错误，还是 RPGItem ID 未注册，方便排查配置。

十五、木桩虚拟生命
------------------
config.yml：
dummy:
  max-health: 1000000

Minecraft 原版实体最大生命属性存在硬上限，因此木桩使用独立的虚拟生命值保存配置，不再要求实体自身真正拥有相同数量的生命。
木桩名称中的 HP 显示虚拟生命配置。近战、弹射物、技能射线、范围伤害和反击命中木桩时只记录伤害与 DPS，不会实际杀死木桩。
虚拟生命值可以超过 2048，也可以设置为更大的测试数值。木桩仍会播放受击动画，并在每次伤害后恢复实际载体生命。
