EarthRPGItem 武器命中药水效果手册（版本 1.3）

一、全局开关
config.yml:
features:
  hit-buffs: true
hit-buffs:
  enabled: true

也可以在 /EarthRPGitem gui -> Setting 中点击“命中药水效果”按钮全局关闭。

二、武器文本写法
hit-buffs:
  SLOWNESS:
    amplifier: 0
    duration-seconds: 5

amplifier 从 0 开始，0 表示 I，1 表示 II。
duration-seconds 是持续秒数。
