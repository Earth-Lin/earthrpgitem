EarthRPGItem FSkill 使用手册 版本1.9

一、基础说明
FSkill 是 RPGItem 的 F 键技能系统。
玩家手持带有 fskill 配置的 RPGItem 时，按 F 键会取消原版副手切换，并释放该物品配置的全部 FSkill。
没有 fskill 的 RPGItem 不会提示玩家，也不会阻止普通提示逻辑之外的功能。
每个玩家、每个 RPGItem 都有独立 CD，不是全局冷却。

二、基础格式
fskill:
  cooldown-seconds: 5
  particles: {}
  switches: {}
  buffs: {}
  damages: {}

cooldown-seconds 表示技能冷却时间，单位秒。
冷却完成时会提示：<rpgitem名字>F技能已就绪。
冷却中按 F 会提示：<rpgitem名字>F技能冷却:<秒数>，秒数保留两位小数。

三、粒子技能 particles
示例：
fskill:
  cooldown-seconds: 4
  particles:
    burst:
      enabled: true
      particle: HEART
      effect: grow
      count: 40
      radius: 2
      repeating: true
      duration-seconds: 3
      interval-seconds: 0.5

enabled：是否开启这一段粒子。
particle：原版粒子类型，如 HEART、DUST、BLOCK、CRIT、END_ROD。
effect：粒子形状，可使用 grow 扩大、contract 收缩、fall 坠落、rise 飞升、spin 旋转、compress 压缩、splash 扩散、circle 圆圈、sphere 球形。
count：每次生成的粒子数量。
radius：粒子半径。
repeating：是否持续触发。
duration-seconds：持续时间。
interval-seconds：每隔多少秒触发一次。

四、切换物品 switches
切换为另一个 RPGItem：
fskill:
  cooldown-seconds: 2
  switches:
    next:
      rpgitem: fskill_switch_tool_axe
      timed: false
      switched-item-cooldown: false

切换材质但保留原有属性和耐久：
fskill:
  switches:
    axe:
      material: DIAMOND_AXE
      timed: true
      duration-seconds: 5
      switched-item-cooldown: true

rpgitem：切换到指定注册物品。
material：只改变手持物品材质，例如 DIAMOND_PICKAXE 改成 DIAMOND_AXE。
timed：开启后到时间自动变回原物品。
duration-seconds：切换持续时间。
switched-item-cooldown：切换后的物品是否立刻进入冷却。

五、药水效果 buffs
示例：
fskill:
  buffs:
    speed:
      type: SPEED
      amplifier: 1
      duration-seconds: 6

type：原版药水效果英文 ID，例如 SPEED、STRENGTH、REGENERATION、NIGHT_VISION。
amplifier：等级，从 0 开始，0 表示一级。
duration-seconds：持续时间，单位秒。

六、伤害技能 damages：光波 wave
示例：
fskill:
  damages:
    wave:
      mode: wave
      damage: 5
      weapon-percent: 80
      length: 7
      radius: 0.8
      repeating: false
      particles:
        enabled: true
        particle: DUST
        color: "255,255,0"
        effect: line
        count: 3
        radius: 0.05

mode: wave 表示向玩家面前发射光波。
damage：固定伤害。
weapon-percent：按当前武器 Attack 属性百分比追加伤害。
length：光波长度。
radius：光波判定半径。
repeating：是否持续生成并持续造成伤害。
duration-seconds：持续时间。
interval-seconds：伤害间隔。
particles：光波粒子配置。

七、伤害技能 damages：范围 area
示例：
fskill:
  damages:
    area:
      mode: area
      damage: 10
      weapon-percent: 100
      radius: 5
      height: 5
      repeating: true
      duration-seconds: 3
      interval-seconds: 1
      particles:
        enabled: true
        particle: DUST
        color: "0,255,255"
        effect: circle
        count: 80
        radius: 5

mode: area 表示以玩家脚下为中心扩散。
radius：圆形范围半径。
height：高度限制，默认建议 5。
伤害会判定为玩家造成，破除目标无敌帧，适合后续与其他插件识别玩家来源。

八、测试模板
fskill_particle_sword：持续爱心粒子测试剑。
fskill_wave_sword：向前发射光波测试剑。
fskill_switch_tool_pickaxe / axe / shovel / hoe：四形态工具，按 F 在稿、斧、铲、锄之间切换，CD 2 秒，带 Fix/s、时运3、效率4。

九、光波与扩散命中控制
damages 下可以增加：
hit-once-per-cast: true
开启后，一次技能释放中同一个实体只会受到一次伤害。
建议光波 wave 默认开启，否则体型大的实体可能被多个光波采样点重复命中。

十、伤害技能音效
光波 wave 和扩散 area 都可以在同一段 damages 下添加 sound：
sound:
  enabled: true
  sound: ENTITY_PLAYER_ATTACK_SWEEP
  volume: 1.0
  pitch: 1.2
sound 是原版音效名，volume 是音量，pitch 是音调。

音调配置说明：
1. 伤害技能使用 fskill.damages.<技能名>.sound.pitch。
2. 独立音效技能推荐使用 fskill.sounds.<技能名>.pitch。
3. 只有一个释放音效时，也支持直接写 fskill.sound.pitch；其中 sound 节点必须与 enabled、sound、volume、pitch 同级。
4. RSkill 和 LSkill 的写法完全相同，只需把 fskill 换成 rskill 或 lskill。
5. pitch 使用小数，例如 0.5、1.0、1.5、2.0。物品根节点 sounds.pitch 是普通攻击命中音效，不是技能释放音效。

十一、独立音效技能 sounds
sounds:
  chime:
    enabled: true
    sound: BLOCK_AMETHYST_BLOCK_CHIME
    volume: 1.0
    pitch: 1.4
    repeating: true
    duration-seconds: 2
    interval-seconds: 0.4
repeating 为 true 时会持续播放，duration-seconds 是持续时间，interval-seconds 是播放间隔。

十二、个人广播 broadcasts
broadcasts:
  title:
    text: "星辉降临"
    color: "&d"
    duration-seconds: 3
广播以标题形式显示，只有当前释放技能的玩家能看到。

十三、文本消息 messages
messages:
  whisper:
    self-only: false
    radius: 10
    repeating: true
    duration-seconds: 3
    interval-seconds: 1
    texts:
      - "&8{player} 的影子正在低语..."
self-only 为 true 时只有自己看到。
self-only 为 false 时，半径 radius 内玩家都会收到文本。
texts 支持多行，{player} 会替换成释放技能的玩家名。

十四、FSkill、RSkill、LSkill 提示开关
config.yml 中可以分别控制三种触发方式的聊天提示：
fskill:
  fskill-messages-enabled: true
  rskill-messages-enabled: false
  lskill-messages-enabled: false

FSkill 默认显示释放、冷却和就绪提示。
RSkill 与 LSkill 默认关闭全部技能提示，技能本身仍正常释放。
需要调试右键或左键技能时，可把对应选项改为 true。

十五、水平散射与地面扩散
wave 模式的 spread-count 会在玩家面朝方向左右展开，所有射线保持在同一水平面，不再向上或向下偏移。
spread-angle 控制水平扇形的总角度，shotgun: true 可以作为霰弹配置标记使用。

示例：
rskill:
  damages:
    shotgun:
      mode: wave
      damage: 8
      length: 6
      radius: 0.4
      spread-count: 7
      spread-angle: 50
      shotgun: true
      pierce: true

area 模式粒子固定在玩家脚下生成，并以八层同心圆铺开。particles.count 越大，每一圈越密集；particles.radius 控制粒子扩散半径。

十六、LSkill 攻速与 AttackRange
LSkill 使用玩家全局 AttackSpeed 冷却。技能释放后，即使切换其他近战 RPGItem，也必须等待当前冷却结束后才能再次造成伤害。
LSkill 命中会播放物品根配置 sounds 中的武器打击音效。
当装备具有 AttackRange 时，技能首个命中会以目标为中心对范围内其他生物造成同等技能伤害。范围伤害不会继续触发第二层范围扩散。
============================================================
2.1 补充：吟唱、长射线、伤害来源与音效
============================================================

一、吟唱 chants
---------------
吟唱存在时，技能激活后先按顺序播放文本。全部文本播放结束后，才释放同一技能节点中的所有粒子、声音、广播、消息、命令、Buff、伤害和物品切换。

fskill:
  cooldown-seconds: 8
  chants:
    oath:
      interval-seconds: 1.0
      texts:
        - "&6第一道封印解除"
        - "&e第二道封印解除"
        - "&f圣剑，释放！"
  damages:
    beam:
      mode: wave
      damage: 10
      length: 100

上例会立即显示第一行，每隔 1 秒显示下一行，最后一行结束后发射 beam。
chants 可以用于 FSkill、RSkill、LSkill，也可以与切换物品、药水、命令等任意技能组合。

二、长射线
----------
单个射线使用 length 设置长度，例如 length: 100 表示 100 格。
服务器 config.yml 提供保护上限：

fskill:
  max-ray-length: 512
  ray-step: 0.4

max-ray-length 是服务器允许的最大射线长度，可以继续调大。
ray-step 是射线检测间距，越小越密集但消耗越高，建议保持 0.3 至 0.5。
2.1 起射线粒子使用强制远距离发送，不再在普通粒子视距约 20 至 32 格处消失。

三、射线伤害类型
----------------
damages 节点新增 damage-type：
PHYSICAL 物理，受 Armor 影响。
MAGIC 魔法，受 MagicArmor 影响。
BOW 或 PROJECTILE 弹射物，受 BowArmor 影响。
TRUE 真实伤害，不受护甲和 Resistance 影响。
ICE、FIRE、LIGHT、DARK 为元素伤害，只受对应元素护甲和 Resistance 影响。

十四、2.1 吟唱阶段、开始释放与收缩粒子
========================================
吟唱中的每一条文本都代表一个阶段。阶段开始时会立即发送该段文本，并播放该阶段的粒子与音效。
第一阶段从技能触发的第 0 tick 开始，因此可以作为“吟唱开始音效”和“吟唱开始粒子”。

完整格式：
chants:
  oath:
    interval-seconds: 1.0
    release-at: end
    particles:
      enabled: true
      particle: DUST
      color: "80,180,255"
      effect: contract
      count: 48
      radius: 4.0
    sound:
      enabled: true
      sound: BLOCK_BEACON_POWER_SELECT
      volume: 1.0
      pitch: 0.8
    stages:
      stage_1:
        text: "&b第一阶段：魔力聚集"
      stage_2:
        text: "&e第二阶段：术式展开"
        particles:
          enabled: true
          particle: END_ROD
          effect: rise
          count: 30
          radius: 2.0
        sound:
          enabled: true
          sound: BLOCK_AMETHYST_BLOCK_CHIME
          volume: 1.0
          pitch: 1.2

默认效果规则：
1. stages 内没有 particles 时，使用吟唱节点外层的 particles。
2. stages 内没有 sound 时，使用吟唱节点外层的 sound。
3. 旧版 texts 列表仍然有效，每条文本自动成为一个阶段，并使用外层默认效果。
4. effect: contract 或 effect: 收缩 会在玩家周围生成粒子，并在本阶段 interval-seconds 时间内持续向玩家脚下聚集。
5. 收缩粒子会跟随玩家当前位置，阶段结束时全部汇聚到脚下。count 越大越密集，radius 控制初始生成半径。

release-at 控制其他技能何时释放：
- end：默认值，吟唱全部结束后释放伤害、切换物品、Buff、广播等技能。
- start：吟唱第一阶段开始时立即同时释放其他技能，吟唱继续播放，结束时不重复释放。
- both：吟唱开始时释放一次，全部结束后再释放一次。

切换物品中断吟唱：
chants:
  oath:
    interval-seconds: 1.0
    interrupt-on-item-switch: true
    release-at: end
    texts:
      - "&b正在聚集魔力……"
      - "&e术式即将完成……"

interrupt-on-item-switch 默认为 true。玩家在吟唱期间切换主手快捷栏物品时，会立即取消尚未播放的文本、粒子、音效和吟唱结束后的技能释放。
该次 FSkill/RSkill 冷却会立即清零；LSkill 使用的玩家全局攻速冷却也会立即清零。
如果设置为 false，玩家切换物品后吟唱仍会继续，结束时仍会释放技能。
注意：release-at: start 已经在吟唱开始时释放的技能无法撤回。需要“切换物品后完全不生效”时应使用 release-at: end。

开始时立即释放示例：
chants:
  battle_cry:
    interval-seconds: 1.0
    release-at: start
    texts:
      - "&6力量已经解放！"
      - "&e术式仍在持续！"

十五、2.1 技能多类型伤害数字
============================
技能的 weapon-percent-sources 会按照伤害来源分别结算和显示，不再合并为 damage-type 的单行数字。
例如来源同时包含 ATTACK、MAGIC_DAMAGE、LIGHT_DAMAGE，目标会看到物理、魔法、光元素三行伤害数字；各种护甲也分别处理对应伤害。
支持来源：ATTACK、MAGIC_DAMAGE、POTION_DAMAGE、BOW_DAMAGE、TRUE_DAMAGE、ICE_DAMAGE、FIRE_DAMAGE、LIGHT_DAMAGE、DARK_DAMAGE、PCT_DAMAGE、PST_DAMAGE、ALL。
POTION_DAMAGE 使用魔法伤害数值，并按药水/魔法伤害显示与 MagicArmor 结算。
damage 字段本身仍使用 damage-type 指定类型；weapon-percent-sources 中的每项使用自身真实类型。

示例：
  damage-type: LIGHT

四、weapon-percent 的伤害来源
-----------------------------
weapon-percent-sources 可以让百分比伤害读取多个属性，不再固定只读取 Attack。

weapon-percent: 500
weapon-percent-sources:
  - ATTACK
  - MAGIC_DAMAGE
  - LIGHT_DAMAGE

支持：ATTACK、MAGIC_DAMAGE、BOW_DAMAGE、TRUE_DAMAGE、ICE_DAMAGE、FIRE_DAMAGE、LIGHT_DAMAGE、DARK_DAMAGE、PCT_DAMAGE、PST_DAMAGE。
填写 ALL 会读取 Attack、MagicDamage、BowDamage、TrueDamage 和四种元素固定伤害。
PctDamage 与 PstDamage 原有的技能附加结算继续保留；再次把它们写入 sources 会额外参与 weapon-percent 倍率，请按需要使用。

五、技能音效排错
----------------
你的模板使用了 ENTITY_TNT_EXPLODE，该名称在 Paper 1.21.1 无效，所以旧代码捕获异常后没有声音。
正确名称为 ENTITY_GENERIC_EXPLODE。2.1 已增加旧名称兼容，并会在后台明确报告其他无效音效名称。

伤害节点音效必须放在 damages.<名字>.sound 下；普通 sounds 节点则是独立技能音效。两者都会在吟唱结束后播放。
