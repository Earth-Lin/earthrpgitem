EarthRPGItem 使用方式汇总表
版本：3.0 稳定版

一、安装与更新

| 场景 | 操作 | 说明 |
|---|---|---|
| 安装插件 | 将 EarthRPGItem-3.0.jar 放入服务器 plugins 目录后启动 | 目标为 Paper 1.21.1、Java 21 |
| 更新插件 | 完全停止服务器，替换旧 JAR，再启动 | 不建议使用 /reload 更新 JAR |
| 修改 RPGItem YAML | 修改 plugins/EarthRPGItem 下对应分类文件 | 修改后执行 /rpgitem reload |
| 查看版本 | 查看启动消息 | 启动消息会显示版本号 |

二、命令表

| 命令 | 权限 | 作用 |
|---|---|---|
| /rpgitem my | earthrpgitem.my | 查看自己的 RPG 属性统计 |
| /rpgitem gui | earthrpgitem.gui | 打开 RPGItem 管理 GUI |
| /rpgitem accessorygui | earthrpgitem.gui | 打开饰品 GUI |
| /rpgitem dummy | earthrpgitem.dummy | 假人测试相关操作 |
| /rpgitem give | 管理权限 | 管理员领取 RPGItem |
| /rpgitem puton | 管理权限 | 管理员为目标装备物品 |
| /rpgitem reload | earthrpgitem.admin | 重载配置、RPGItem 和采集数据 |
| /rpgitem collection refresh [世界名|all] | 管理权限 | 刷新采集点 |
| /rpgitem skillforge | earthrpgitem.skillforge | 打开技能强化台（技能等级成长） |
| /rpgitem gathering [玩家] | 本人可用，查别人需 earthrpgitem.admin | 采集诊断：三分类手持工具采掘等级 / 资源点数量（带经验/带门槛各几个） |

命令别名：/EarthRPGitem、/erpgitem、/rpgitem。具体参数以服务器 tab 补全为准。

三、RPGItem YAML 基础表

| 配置 | 示例 | 作用 |
|---|---|---|
| id | id: flame_staff | 物品唯一 ID |
| material | material: BLAZE_ROD | 物品材质 |
| display-name | display-name: "&c火焰法杖" | 显示名称 |
| description | description: ["&7说明"] | 物品 Lore |
| attributes | attributes: {Attack: 10} | RPG 属性 |
| fskill/rskill/srskill | fskill: | F、站立右键、蹲下右键技能 |
| qskill/sqskill | qskill: | Q、蹲下 Q 技能 |
| lskill | lskill: | 左键/近战技能 |
| buffs | buffs: | 持有或装备时提供药水效果 |
| hit-buffs | hit-buffs: | 命中时施加效果 |
| vanilla-attributes | vanilla-attributes: | 原版 AttributeModifier |
| soulbound | soulbound: true | 生存模式首次生效后绑定 UUID |
| consumables | consumables: true | 技能释放时按配置消耗 |
| unbreakable | unbreakable: true | 不按普通耐久损坏 |
| level | level: 10 | 等级限制 |
| Deputy | Deputy: true | 副手/辅助装备定位 |

四、技能触发表

| 节点 | 触发方式 | 说明 |
|---|---|---|
| fskill | F/换手键 | F 技能 |
| rskill | 站立右键 | 普通右键技能 |
| srskill | 蹲下右键 | 蹲下右键技能 |
| qskill | Q/丢弃键 | 站立 Q 技能 |
| sqskill | 蹲下 Q | 蹲下 Q 技能 |
| lskill | 左键或近战命中 | 近战技能 |

主手和副手同时有 RPGItem 时，Q/SQ 优先使用拥有当前对应技能的主手物品，否则回退到副手物品。空手或仅副手持有 RPGItem 时允许正常丢弃。

五、技能效果节点

| 节点 | 常用字段 | 作用 |
|---|---|---|
| particles | particle、effect、count、duration | 播放粒子 |
| sounds | sound、volume、pitch | 播放声音 |
| messages | texts、self-only、radius | 发送消息 |
| broadcasts | text、color、duration | 广播文本 |
| commands | commands、as-op | 执行命令或消息 |
| buffs | type、amplifier、duration-seconds | 施加药水效果 |
| damages | mode、damage、damage-type、radius、length | 造成技能伤害 |
| dash | distance、duration-ticks、invulnerability-ticks | 直线突进 |
| roll | distance、duration-ticks、invulnerability-ticks | 翻滚 |
| range-buffs | radius、height、target、effects | 范围增益/治疗 |
| chants | stages、interval、release-at-start/end | 吟唱分阶段执行 |
| switches | rpgitem、material、duration | 切换物品或材质效果 |

六、全局冷却表

| 项目 | 默认值 | 说明 |
|---|---|---|
| global-cooldown | true | 每个技能节点默认开启 |
| global-cooldown-seconds | 未填写 | 默认使用 cooldown-seconds |
| 触发类型 | F/R/SR/Q/SQ/L 分开 | 同类型技能共享，不同类型互不影响 |
| 关闭方式 | global-cooldown: false | 写在具体技能节点内 |
| 额外注册 | 不需要 | YAML 配置后执行 /rpgitem reload |

示例：
qskill:
  cooldown-seconds: 5
  global-cooldown: true
  global-cooldown-seconds: 8
  dash:
    distance: 5

七、属性使用流程

| 步骤 | 操作 |
|---|---|
| 1 | 在 Armor、Tool、Weapon、Items 或 Accessory 对应目录创建 .yml/.yaml/.txt |
| 2 | 写入 id、material、display-name 和属性/技能节点 |
| 3 | 执行 /rpgitem reload |
| 4 | 使用 GUI 或管理员命令领取物品 |
| 5 | 用 /rpgitem my 查看汇总属性 |
| 6 | 用假人或实际战斗测试伤害、冷却和效果 |

八、采集系统

| 内容 | 使用方式 |
|---|---|
| 采集类型 | 农业、挖掘、伐木 |
| 采集属性 | FarmingSpeed、MiningSpeed、ForestSpeed、FarmingFortune、MiningFortune、ForestFortune |
| 采集点数据 | plugins/EarthRPGItem/collection-points.yml |
| 刷新命令 | /rpgitem collection refresh [world|all] |
| 放置与删除 | 按权限在创造模式操作 |
| 农业采集 | 右键采集，避免普通小麦掉落逻辑干扰 |

九、GUI、饰品与测试

| 功能 | 使用方式 |
|---|---|
| 主 GUI | /rpgitem gui，按 Armor、Tool、Weapon、Items、Accessory、Collection 浏览 |
| 饰品 | /rpgitem accessorygui，按饰品槽规则装备 |
| 属性查看 | /rpgitem my |
| 假人测试 | /rpgitem dummy，测试伤害、暴击、抗性和技能 |
| 资源模板 | 使用项目根目录或手动模板中的 YAML，复制到服务器插件目录 |

十、常见问题

| 问题 | 处理 |
|---|---|
| YAML 修改后没生效 | 确认目录正确并执行 /rpgitem reload |
| JAR 更新后代码没变化 | 完全停止服务器后替换 JAR 并重启 |
| 技能不释放 | 检查 features.fskill、节点名称、冷却和玩家姿态 |
| 全局冷却疑问 | 默认 true；具体技能写 global-cooldown: false 可关闭 |
| 物品无法使用 | 检查 type、level、soulbound、耐久和配置 |
