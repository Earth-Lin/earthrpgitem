EarthRPGItem 伤害数字颜色使用手册（版本 1.3）

一、开关位置
config.yml:
damage-display:
  enabled: true
  duration-seconds: 3
  random-range: 1.0

二、颜色配置
physical-color: "&c"       # 普通物理伤害颜色 / Physical damage color
physical-crit-color: "&6"  # 物理暴击伤害颜色 / Physical critical color
magic-color: "&d"          # 普通魔法伤害颜色 / Magic damage color
magic-crit-color: "&5"     # 魔法暴击伤害颜色 / Magic critical color
true-color: "&4"           # 真实伤害颜色 / True damage color

三、格式配置
physical-format: "🗡❤-{damage}"
physical-crit-format: "⚔❤-{damage}"
magic-format: "✡❤-{damage}"
magic-crit-format: "🔯❤-{damage}"
true-format: "☠❤-{damage}"

{damage} 会被替换为最终整数伤害，插件已经去掉了旧版中的 = 符号。
支持 Minecraft 原版 & 颜色代码，例如 &c 红色、&6 金色、&d 紫色、&f 白色。
