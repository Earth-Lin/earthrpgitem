EarthRPGItem 1.5 弓箭/弩弹射物粒子特效手册

一、基础说明
1. 只有被识别为 RPGItem 的 BOW 或 CROSSBOW 才会启用本系统。
2. 弓箭/弩命中实体时，插件会强制清除目标无敌帧，并使用玩家作为伤害来源结算，方便其他插件识别为玩家造成的伤害。
3. 弓箭/弩近战敲击目标时，只会触发 +Attack，不会触发 +MagicDamage、+BowDamage、+TrueDamage、背击、刺客等弹射物/特殊伤害。
4. 伤害数字会在目标附近显示：普通弓箭为 🏹❤-(生命值)，弓箭暴击为 🏹⭐❤-(生命值)。

二、全局开关 config.yml
features:
  projectile-trail-particles: true   # 弹道粒子总开关 Projectile trail particle master switch
  projectile-hit-particles: true     # 命中粒子总开关 Projectile hit particle master switch
  projectile-sounds: true            # 拉弓、弹道、命中声音总开关 Projectile sound master switch

projectile-draw-sound:
  enabled: true                      # 是否启用拉弓提示音
  sound: BLOCK_NOTE_BLOCK_PLING      # 声音类型，使用 Bukkit/Paper Sound 名称
  volume: 0.35                       # 音量
  low-pitch: 0.6                     # 刚开始拉弓的低音调
  high-pitch: 1.4                    # 普通满弓音调，EXDraw 会继续提高

projectile-trail-particles:
  enabled: true                      # 默认弹道粒子是否启用
  particle: DUST                     # 粒子类型，DUST 可配 RGB 颜色
  color: "128,128,128"               # DUST 颜色，灰色示例
  count: 2                           # 每 tick 粒子数量，不建议过高
  radius: 0.05                       # 围绕弹射物的小范围随机半径

projectile-trail-sound:
  enabled: false                     # 默认关闭；单个 RPGItem 可改成 true
  sound: ENTITY_FIREWORK_ROCKET_BLAST # 默认类似烟花飞升声
  volume: 0.18
  pitch: 1.2

projectile-hit-particles:
  enabled: true
  particle: FIREWORK                 # 命中爆炸粒子类型
  effect: current                    # current=当前随机爆开；circle/sphere/round/圆形=圆形扩散
  color: "128,128,128"               # DUST 时生效
  count: 80                          # 爆炸总粒子数量
  radius: 1.2                        # 爆炸半径

projectile-hit-sound:
  enabled: true
  sound: ENTITY_FIREWORK_ROCKET_BLAST
  volume: 1.0
  pitch: 1.0

如果单个弓或弩没有填写 projectile-hit-particles，插件会继承服务器 config.yml 的 projectile-hit-particles 配置。
服务器默认 enabled: true，因此省略该节点时仍会产生 FIREWORK 命中爆炸粒子。只有全局开关关闭，或物品明确填写 enabled: false 时才关闭。

三、单个 RPGItem 文本写法
在 Weapon 文件夹的弓或弩文本中加入：

projectile-trail-particles:
  enabled: true
  particle: DUST
  color: "128,128,128"
  count: 2
  radius: 0.05

projectile-trail-sound:
  enabled: true
  sound: ENTITY_FIREWORK_ROCKET_BLAST
  volume: 0.18
  pitch: 1.2

projectile-hit-particles:
  enabled: true
  particle: FIREWORK
  effect: circle
  count: 80
  radius: 1.2

projectile-hit-sound:
  enabled: true
  sound: ENTITY_FIREWORK_ROCKET_BLAST
  volume: 1.0
  pitch: 1.0

四、命中爆炸 effect 样式
1. current：当前样式，粒子在命中点附近随机炸开，适合破碎、飞溅、普通烟花感。
2. circle / sphere / round / 圆形：圆形扩散样式，粒子从命中点向外变成一个大圆/球面，适合满弓爆炸、魔法箭、范围冲击感。

五、伤害数字颜色
在 config.yml 的 damage-display 中配置：
magic-color: "&d"          # 魔法伤害：紫色
magic-crit-color: "&5"     # 魔法暴击：深紫色
physical-crit-color: "&6"  # 物理暴击：金色
true-color: "&c"           # 真实伤害：红色
bow-color: "&a"            # 弓箭普通伤害：浅绿色
bow-crit-color: "&2"       # 弓箭暴击伤害：深绿色

如果服务器已经生成过旧 config.yml，插件不会强制覆盖你的旧配置。请手动把以上字段补进 plugins/EarthRPGItem/config.yml 后重启或重载插件。

六、性能建议
1. 弹道粒子每 tick 跟随弹射物生成，count 建议 1-4。
2. 命中爆炸 count 建议 40-120，半径建议 0.8-2.0。
3. 弹道声音每 tick 播放会比较吵，建议只给少量测试武器开启，或调低 volume。
4. 大量玩家同时使用高 count 粒子时，应优先降低 projectile-trail-particles.count。
七、拉弓、弩装填与 EXDraw 阶段说明
1. 普通弓：按住右键开始计时，发射时按本次拉弓时间计算伤害。
2. 弩：按住右键开始计时，装填完成时保存本次装填阶段，真正发射时读取保存的阶段。
3. EXDraw 只会在拉满后生效。基础满弓约为 1 秒，之后每多拉/装填 1 秒增加 1 个阶段。
4. 阶段数量上限由 +EXDraw 决定。例如 +EXDraw: 8，最多有 8 个追加阶段。
5. 每个追加阶段默认提升 15% 弹射物伤害，同时拉弓提示音提高 1 个阶段音调。
6. 没有拉满弓时不会获得 EXDraw 追加阶段，只按原版拉弓力度折算，最低 20%。
7. 如果关闭 projectile-sounds，拉弓计时仍会正常工作，只是不播放提示音。
8. 快速装填弩在装填结束后会清理拉弓状态，避免声音一直循环。

八、弹道声音 interval-ticks
projectile-trail-sound:
  enabled: true
  sound: ENTITY_FIREWORK_ROCKET_BLAST
  volume: 0.18
  pitch: 1.2
  interval-ticks: 4

说明：
1. interval-ticks 是弹道声音播放间隔，20 tick = 1 秒。
2. 默认 4 tick 表示约每 0.2 秒播放一次，适合烟花飞升声。
3. 弹道粒子仍然每 tick 跟随弹射物生成，不受声音间隔影响。

九、F 键副手切换限制
1. 玩家主手或副手拿着 RPGItem 时，插件会取消 F 键切换副手。
2. 这样可以为后续 F 键武器技能预留输入通道。
3. 普通非 RPGItem 不受影响。
