EarthRPGItem YML 多物品与皮革颜色使用手册
==========================================

一、支持的文件格式
------------------
Armor、Tool、Weapon、Accessory 四个目录现在都支持：
- .txt：原有格式，继续完全兼容。
- .yml：标准 YAML 文件。
- .yaml：标准 YAML 文件。

修改文件后执行 /rpgitem reload 重新加载注册表。

二、单文件单物品
----------------
TXT、YML、YAML 都可以继续使用原来的根节点结构：

id: fire_sword
material: DIAMOND_SWORD
display-name: "&c烈焰剑"
attributes:
  Attack: 12
  FireDamage: 8
description:
  - "&7燃烧着火焰的长剑。"

如果不填写 id，插件使用文件名作为默认 ID。例如 fire_sword.yml 的默认 ID 是 fire_sword。

三、单个 YML 文件编写多个物品
-------------------------------
推荐在文件根节点使用 items：

items:
  iron_sword_a:
    material: IRON_SWORD
    display-name: "&f铁剑 A"
    attributes:
      Attack: 5
      Fix/5s: 1
    description:
      - "&7每五秒恢复一点耐久。"

  magic_sword_b:
    material: GOLDEN_SWORD
    display-name: "&d魔法剑 B"
    attributes:
      Attack: 3
      MagicDamage: 10
    sounds:
      enabled: true
      sound: BLOCK_AMETHYST_BLOCK_CHIME
      volume: 1.0
      pitch: 1.2
    description:
      - "&7物理和魔法伤害可以同时生效。"

items 下一级的键就是默认物品 ID。本例注册 iron_sword_a 和 magic_sword_b。
物品内部仍可填写 id: other_id 覆盖节点键，但为了方便维护，建议节点键与 id 保持一致。

四、技能配置保持不变
--------------------
多物品节点中的每件物品都支持完整的 fskill、rskill、lskill、粒子、音效、Buff、附魔和吟唱配置：

items:
  chant_staff:
    material: BLAZE_ROD
    display-name: "&6吟唱法杖"
    attributes:
      MagicDamage: 15
    fskill:
      cooldown-seconds: 5
      chants:
        spell:
          interval-seconds: 1
          interrupt-on-item-switch: true
          release-at: end
          texts:
            - "&e第一阶段"
            - "&6第二阶段"
      damages:
        beam:
          mode: wave
          damage-type: MAGIC
          damage: 20
          length: 40
          radius: 1

五、皮革护甲颜色
----------------
只有 LEATHER_HELMET、LEATHER_CHESTPLATE、LEATHER_LEGGINGS、LEATHER_BOOTS 会应用颜色。

RGB 格式：

items:
  red_leather_chestplate:
    material: LEATHER_CHESTPLATE
    display-name: "&c赤红皮甲"
    leather-color: "255,0,0"
    attributes:
      Armor: 5

十六进制格式：

items:
  blue_leather_boots:
    material: LEATHER_BOOTS
    display-name: "&9深蓝皮靴"
    leather-color: "#2050FF"
    attributes:
      Armor: 2

RGB 每项允许 0 到 255。无效颜色会在后台显示警告，并使用原版皮革颜色。
非皮革材质可以保留 leather-color 字段，但插件会直接忽略。

六、直接使用物品 ID
--------------------
多物品 YML 注册完成后，与 TXT 物品没有区别：

/rpgitem give 玩家名 iron_sword_a
/rpgitem puton 玩家名 red_leather_chestplate

这些物品也会自动进入对应的 Weapon、Armor、Tool 或 Accessory GUI。

七、模板生成规则
----------------
目录中存在任意 .txt、.yml 或 .yaml 文件时，插件都认为该目录已有配置，不会生成自带测试模板。
只有对应目录完全没有这三种配置文件时，才会在服务器启动时生成默认模板。

八、注意事项
------------
1. 同一个文件内不要重复使用相同节点键。
2. 不同文件也不要注册相同 ID，否则指令和 GUI 可能只能找到其中一个。
3. YAML 缩进必须使用空格，不能使用 Tab。
4. 包含 #、冒号、颜色代码或特殊字符的文本建议使用双引号。
5. TXT 文件本质上仍按 YAML 语法读取，因此原有 TXT 配置不需要迁移。

九、伤害数字前缀
----------------
伤害数字的图标或文字前缀可以在服务器 config.yml 的 damage-display 中自由修改，后面的伤害数字始终由插件结算：

damage-display:
  prefix-enabled: true
  physical-prefix: "物理-"
  physical-crit-prefix: "暴击-"
  magic-prefix: "魔法-"
  magic-crit-prefix: "魔法暴击-"
  bow-prefix: "弓箭-"
  bow-crit-prefix: "弓箭暴击-"
  true-prefix: "真实-"
  ice-prefix: "冰-"
  fire-prefix: "火-"
  dark-prefix: "暗-"
  light-prefix: "光-"

例如最终伤害是 125，physical-prefix 设置为 "物理-" 时显示为：物理-125。
前缀可以使用 & 颜色代码、中文、英文、空格和 Emoji。只修改前缀，不需要填写 {damage}。
prefix-enabled 默认为 false，此时继续使用旧版 physical-format、magic-format 等完整模板。
只有设置 prefix-enabled: true 后，才会优先使用对应 prefix；这样升级插件不会覆盖或停用服主原有的伤害显示模板。

十、原版附魔写法
----------------
列表格式继续兼容：

enchantments:
  - "SHARPNESS:4"
  - "UNBREAKING:3"

YML 映射格式也可以使用：

enchantments:
  SHARPNESS: 4
  UNBREAKING: 3

两种格式效果相同。SHARPNESS 锋利会进入插件接管后的物理伤害结算，并显示在物理伤害数字中。
十一、连续 id 多物品格式
------------------------
同一个 .yml 或 .yaml 文件现在可以连续编写多件 RPGItem。每个没有缩进、位于行首的 id: 都代表一件新物品：

id: best_iron_sword_in_village
material: IRON_SWORD
display-name: "&f全村最好的铁剑"
attributes:
  Attack: 5
description:
  - "&f第一把武器"

id: flower_blade
material: IRON_SWORD
display-name: "&f鲜花战刃"
attributes:
  Attack: 7
description:
  - "&f第二把武器"

插件会在读取标准 YAML 前先识别这些顶层 id，并把每一段作为独立 RPGItem 注册，因此前一件物品不会再被后面的重复键覆盖。
id: 必须从行首开始，不能带空格。物品内部的 attributes、description、enchantments、fskill 等节点仍按正常 YAML 缩进。
原有 items:、rpgitems:、根节点物品 ID、单物品 YML 和 TXT 格式继续兼容。大型配置仍推荐使用 items: 包装结构，层次更清楚。
