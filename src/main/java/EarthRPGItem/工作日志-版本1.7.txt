EarthRPGItem 工作日志 - 版本1.7

一、版本更新
1. Gradle 项目版本更新为 1.7。
2. 本版本重点扩展元素战斗系统、生物装备属性生效和弹射物命中清理。

二、弹射物命中清理
1. 修复 RPGItem 弹射物命中实体后仍可能反弹的问题。
2. 弹射物命中实体完成伤害、伤害数字、粒子、范围攻击后会立即 remove。
3. 如果弹射物被玩家格挡，也会立即清除弹射物，避免继续碰撞。

三、元素伤害系统
1. 新增 IceDamage、FireDamage、LightDamage、DarkDamage。
2. 每种元素伤害支持固定值和百分比两种写法：
   - IceDamage: 5
   - IceDamagePercent: 50
   - IceDamage%: 50
3. 元素百分比按本次武器已经打出的非元素最终伤害复制，包含暴击后的伤害。
4. 元素伤害不吃暴击率和暴击伤害加成。
5. 元素伤害只受到完全抵抗 Resistance 和对应元素护甲影响。
6. 元素伤害数字：
   - 冰：🧊❤-(生命值)，蓝色。
   - 火：🔥❤-(生命值)，浅红色。
   - 暗：🌘❤-(生命值)，黑色。
   - 光：☀❤-(生命值)，黄色。

四、元素护甲系统
1. 新增 IceArmor、FireArmor、LightArmor、DarkArmor。
2. 每种元素护甲支持固定值和百分比两种写法：
   - FireArmor: 3
   - FireArmorPercent: 20
   - FireArmor%: 20
3. 元素护甲只抵御对应元素，不抵御其他元素或物理/魔法/真实伤害。
4. 元素护甲会受到 ArmorPen 护甲穿透影响。

五、生物装备属性生效
1. 新增 LivingEntity 装备属性读取入口。
2. 玩家以外的生物穿戴 RPGItem 护甲时，防御、元素护甲等属性可以生效。
3. 玩家以外的生物主手装备 RPGItem 武器时，近战攻击属性可以生效。
4. 非玩家生物不处理等级、灵魂绑定等玩家专属限制。

六、Setting GUI 优化
1. Setting GUI 添加元素伤害和元素护甲开关。
2. 部分按钮名称加入中英文双语言，方便中文服主管理。

七、测试模板
1. 新增 test_ice_element_sword.txt：冰元素测试剑。
2. 新增 test_fire_element_sword.txt：火元素测试剑。
3. 新增 test_light_dark_element_bow.txt：光暗元素测试弓。
4. 新增 test_element_armor.txt：四元素护甲测试胸甲。

八、后续注意
1. 已生成过旧插件数据目录的服务器，需要手动补充 config.yml 新字段，或者备份后删除旧配置让插件重新生成。
2. 已生成过旧 Weapon/Armor 文件夹的服务器，新模板只会在对应文件不存在时创建。
