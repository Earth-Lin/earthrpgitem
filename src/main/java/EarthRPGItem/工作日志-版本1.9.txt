EarthRPGItem 工作日志 版本1.9

一、版本与构建
1. 项目版本更新为 1.9。
2. 新增 FSkills 类，作为 F 键技能系统入口。

二、劈砍粒子优化
1. 劈砍横扫粒子默认半径从较粗的 0.5 调整为 0.22，使刀波更细。
2. 增加 slash-particles.count-multiplier，用于提高粒子数量。
3. 增加 slash-particles.speed-multiplier，用于整体加快刀波动画。
4. 高攻速时最少保留 3 个动画步骤，避免最大攻速时粒子只在边缘或不完整生成。

三、修复指令
1. 新增 /rpgitem fix：修复手持 RPGItem 的原版耐久和 ExDur 附加耐久。
2. 新增 /rpgitem fixs：修复玩家背包、护甲栏、副手中的 RPGItem 耐久和 ExDur。
3. 指令仅 OP 或命令方块可用。命令方块执行时会查找附近 8 格内玩家作为目标。

四、格挡调整
1. 格挡成功后的攻速惩罚从 -50 调整为 -20。
2. 新增 config.yml: parry.attack-speed-penalty，可由服务器自行修改。

五、灵魂绑定增强
1. 饰品 GUI 放入 Soulbound 饰品时会自动绑定玩家名。
2. 如果饰品已绑定其他玩家，非 OP 玩家放入饰品 GUI 后属性不会生效，并且无法装备。
3. 新增拾取保护：灵魂绑定物品只有主人或 OP 可以拾取。

六、假人 DPS 调整
1. 假人 DPS 改为一分钟窗口内“每秒伤害总量”的平均值。
2. 超过一分钟没有新的伤害记录时，旧窗口会清零重新计算。

七、FSkill 系统
1. 支持一个物品同时拥有多种 FSkill，按一次 F 全部释放。
2. 支持粒子技能、物品切换技能、药水效果技能、光波伤害、范围伤害。
3. 技能 CD 为玩家独立、物品独立，不是全局冷却。
4. 冷却完成与冷却中提示已实现，冷却剩余秒数保留两位小数。
5. 伤害技能会强制破除目标无敌帧，并以玩家作为伤害来源。

八、测试物品
1. 新增 fskill_particle_sword，用于测试持续粒子。
2. 新增 fskill_wave_sword，用于测试光波伤害。
3. 新增四形态工具 fskill_switch_tool_pickaxe、axe、shovel、hoe，用于测试 F 键循环切换。

九、技能粒子与提示修正
1. 修复霰弹光波混入 Y 轴偏移的问题，所有散射方向现在保持水平，仅在玩家朝向的左右两侧展开。
2. 扩散技能改为在玩家脚下生成八层同心圆，并提高每圈粒子密度，解决扩散法杖粒子稀疏的问题。
3. 新增 fskill.fskill-messages-enabled、rskill-messages-enabled、lskill-messages-enabled 三个提示开关。
4. FSkill 提示默认开启；RSkill 和 LSkill 的释放、冷却、就绪提示默认关闭。

十、横扫刀波运动与配置
1. 横扫和下落刀波增加沿玩家面朝方向的水平前进运动，与原有横向弧线、纵向下落组合成 X/Y/Z 三轴轨迹。
2. 新增全局配置 slash-particles.length，默认值为 1.2 方块。
3. 每个 RPGItem 可以在自身 slash-particles.length 中覆盖刀波前进距离，便于不同武器制作长短不同的刀波。
4. length 只影响横扫与下落刀波，突刺长度仍由 thrust-diameter 独立控制。

十一、LSkill 攻速冷却修复
1. LSkill 继续使用武器 AttackSpeed 计算独立触发间隔。
2. 技能释放后同步设置手持物品的原版冷却覆盖层，使玩家可以直接看到剩余攻速冷却。
3. 冷却期间的空挥、命中和切换攻击目标都会被同一个玩家与物品冷却记录拦截。

十二、玩家全局攻速冷却
1. 将普通近战与 LSkill 原本分离的冷却记录合并为插件级 AttackCooldownManager。
2. 攻速冷却现在以玩家 UUID 为唯一范围，冷却中切换任何其他 RPGItem 近战武器仍无法造成伤害。
3. LSkill 武器的挥动动画不再被普通近战监听器提前写入冷却，LSkill 释放后由技能系统统一启动全局冷却。

十三、法杖与刀波修正
1. 霰弹方向改为以玩家准星完整方向为中心，保留准星俯仰角，只向左右对称散射。
2. 横扫刀波降低生成高度，主要沿世界 X/Z 水平面扩散，Y 轴轨迹变化限制在一格以内。
3. 下落劈砍轨迹保持原逻辑，不受横扫高度修正影响。
4. LSkill 命中实体后播放 RPGItem 武器打击音效。
5. LSkill 伤害支持 AttackRange 属性，以命中目标为中心扩散同等伤害，且不会递归连锁扩散。
