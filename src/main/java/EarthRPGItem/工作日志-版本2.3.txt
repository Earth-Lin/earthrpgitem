EarthRPGItem 2.3 工作日志
========================

一、版本目标
------------
2.3 增加单件 RPGItem 版本校验、注册属性指纹、整数随机属性和 Minecraft 原版 AttributeModifier 编辑能力。

二、物品版本与属性指纹
----------------------
1. 新增 item-version，兼容根节点 version 别名；该版本属于单件物品，与插件版本无关。
2. 新生成物品在 PDC 保存 item_version 和 attribute_signature。
3. 属性指纹覆盖 RPG 数值属性、随机范围、原版属性、等级、副手、Fix 间隔、损毁保护、灵魂绑定和无法破坏等关键注册信息。
4. PDC 版本或属性指纹与注册表不一致时，findItem 不再返回有效物品，战斗、Buff、耐久、技能和饰品统计统一失效。
5. 无效旧物品不会进入英文描述属性解析，防止通过 Attack +数字 描述绕过注册校验。
6. 插件创建的原版 AttributeModifier 会从已判定失效的旧物品上移除。

三、随机属性
------------
1. 新增 最小值-最大值 整数范围解析，例如 Attack: "5-9"。
2. 每次创建物品独立抽取整数，并保存在 random_attributes PDC；已有物品重启后保持原数值。
3. RpgStats 汇总玩家、非玩家生物、主手、副手、护甲和饰品时读取该物品自己的随机结果。
4. description 支持 Attack +5-9；注册表已有同名 attributes 属性时不重复叠加。
5. 非 RPGItem 英文描述继续支持固定值与随机范围，并兼容前置颜色代码。
6. Fix 随机值接入每秒耐久任务，ExDur 随机值接入生成时附加耐久和描述。

四、原版属性
------------
1. 新增 vanilla-attributes，并兼容 minecraft-attributes 别名。
2. 支持击退抗性、最大生命、攻击伤害、移动速度、护甲、盔甲韧性、攻击速度、幸运、攻击击退和跳跃力量。
3. 支持 ADD_NUMBER、ADD_SCALAR、MULTIPLY_SCALAR_1 三类原版运算。
4. 支持 AUTO 及常用 EquipmentSlotGroup 槽位；AUTO 根据装备材质自动选择。
5. 玩家和生物通过原版装备系统自动获得、移除属性。
6. Accessory 忽略原版属性修饰符，避免手持饰品绕过专属 GUI 生效规则。

五、文档
--------
1. 新增 tips/属性详细使用手册-版本2.3.txt。
2. 新增 tips/原版属性编辑使用手册-版本2.3.txt。
3. 手册包含物品版本、固定值、随机值、描述随机属性、多物品 YML、全部原版属性、运算模式、槽位和完整案例。

六、构建版本
------------
Gradle 项目版本更新为 2.3，目标产物为 EarthRPGItem-2.3.jar。

七、弹射物命中粒子默认值修复
----------------------------
1. 修复弓或弩未声明 projectile-hit-particles 时，物品级默认值错误关闭命中粒子的问题。
2. 省略物品节点时改为继承 config.yml 的 projectile-hit-particles.enabled；服务器默认开启并使用 FIREWORK 命中爆炸。
3. 物品仍可显式配置 projectile-hit-particles.enabled: false，保留单件物品关闭能力。

八、手持旧物品自动更新
----------------------
1. 玩家主手或副手出现属性指纹、item-version 不一致的 RPGItem 时，自动按当前注册表重建物品。
2. 自动更新保留堆叠数量、原版耐久损耗、附加耐久已消耗数值和灵魂绑定主人。
3. 新版随机属性重新抽取并写入 PDC，原版属性修饰符、附魔、名称、描述、技能和特效同步使用最新注册内容。
4. 背包中未持有的物品和 accessory GUI 内物品不自动刷新，继续遵循旧物品属性失效规则。

九、副手弓弹射物伤害限制
------------------------
1. 发射 RPG 弓箭时记录 EntityShootBowEvent 提供的实际手位。
2. 副手 RPG 弓发射的弹射物命中实体时取消事件并移除弹射物，不结算原版伤害、RPG 弓伤、魔法伤害、元素伤害或范围伤害。
3. 主手弓和弩的现有弹射物伤害、粒子与音效流程保持不变。

十、原版属性代码复查与修复
--------------------------
1. 修复 Bukkit 将 minecraft:generic.movement_speed 等包含句点的键拆成配置路径后，旧解析器无法取得 amount、operation 和 slot 的问题。
2. 原版属性加载器改为递归读取实际 YAML 节点，并重建完整命名空间属性名；完整名、GENERIC_ 简写和短名称继续兼容。
3. 修复 PlayerAttributeTask 按 RPG 基础最大生命截断玩家生命、忽略原版 GENERIC_MAX_HEALTH 修饰符的问题；现在按 AttributeInstance.getValue() 的最终值限制生命。
4. 复查确认移动速度、击退抗性、攻击伤害、护甲、韧性、攻击速度、幸运、攻击击退和跳跃力量均使用原版 AttributeModifier 与装备槽位生效。

十一、随机属性失效修复
----------------------
1. 修复范围属性依赖 random_attributes PDC，而 PDC 缺失时注册值回退为 0，导致 Attack: "22-30" 完全不生效的问题。
2. 解析范围后把注册基础值设置为范围下限；即使物品数据异常，属性也不会低于配置下限。
3. 属性汇总时检查并补齐缺失的随机键，将新随机结果重新写回物品 PDC。
4. 版本指纹校验新增随机键完整性检查，缺失随机数据的手持旧物品会进入自动更新流程。
5. 随机范围解析兼容 YAML 返回的任意标量对象，不再只接受 Java String 类型。

十二、随机值重抽与手持更新修复
------------------------------
1. 新增 rpgitem.random-attributes.reroll-on-use，默认 true；每次属性汇总时重新抽取范围整数，使 Attack、BowDamage 等伤害范围在每次使用时实际变化。
2. 配置为 false 时继续使用生成物品时写入 PDC 的固定随机值，兼容固定词条玩法。
3. 修复手持旧物品重建后仅修改局部 ItemStack、部分服务端实现未同步回物品栏的问题。
4. 主手与副手自动更新后显式调用 setItemInMainHand 或 setItemInOffHand，确保新版名称、属性、PDC、附魔与特效立即写回。

十三、名称颜色兼容修复
----------------------
1. 统一名称、Lore、GUI 文本和消息使用增强版 LegacyComponentSerializer。
2. 名称同时支持 `&` 和 `§` 颜色代码，并支持 `&#RRGGBB` 与 `&x&0&0&F&F&F&F` 十六进制颜色。
3. YML、YAML、TXT 和多物品节点均经过相同颜色解析流程，避免格式不同造成颜色表现不一致。
4. `&f`/`§f` 本身代表白色；用户模板中的 `display-name: "&f星辉动力头盔<II>"` 显示白色属于配置指定结果，改用 `&b` 或十六进制颜色即可显示青色。

十四、2.4 版本开发记录
----------------------
1. 新增 Consumables 属性。物品拥有该属性时，FSkill、RSkill、LSkill 任意一种技能成功触发后消耗一件物品；物品数量为 1 时直接清空主手。
2. 修复技能伤害未参与魔法暴击的问题。技能类型为 MAGIC 或 POTION 时，按施法者 CritChance、CritDamage 和目标 CritArmor 独立计算魔法暴击，并显示魔法暴击数字。
3. F、R、L 三类技能现在都能独立配置提示开关、冷却中提示、冷却完成提示和释放提示；旧版 fskill.ready-message、fskill.cooldown-message 继续作为回退配置。
