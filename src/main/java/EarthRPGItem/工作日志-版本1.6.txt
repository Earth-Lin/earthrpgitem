EarthRPGItem 工作日志 - 版本1.6

一、版本更新
1. Gradle 项目版本从 1.5 更新为 1.6。
2. 最终构建产物为 EarthRPGItem-1.6.jar。

二、远程拉弓与发射逻辑修复
1. 拉弓状态在开始前会先清理旧状态，避免快速拉弓或快速装填弩导致音效残留。
2. 玩家切换物品、丢弃物品、退出服务器、F 键切换被拦截时都会清理拉弓状态。
3. 拉弓音效不再依赖弹射物飞行状态，攻击命中后再次拉弓仍会正常播放。
4. EXDraw 阶段重新明确为：拉满后每多 1 秒增加 1 阶段，阶段上限由 EXDraw 属性决定。
5. 每个 EXDraw 阶段都会按 projectile-draw-sound.stage-pitch-step 提升音调。
6. 弹射物飞行音效改为发射音效，默认 ENTITY_FIREWORK_ROCKET_LAUNCH，避免持续飞行声音在服务器中不稳定。

三、新增伤害属性
1. 新增 PctDamage：根据攻击者最大生命值百分比造成物理类型伤害。
2. 新增 PstDamage：根据目标最大生命值百分比造成物理类型伤害。
3. 新增 AttackRange：弹射物命中后对主目标周围生物复制同样最终伤害与伤害图标。
4. 三个属性均支持弓箭/弩弹射物，不在近战中触发。
5. AttackRange 支持小数，计算时允许两位小数配置。

四、新增格挡与反击
1. 新增 Parry：玩家受到近战物理或弹射物伤害时有概率格挡。
2. 格挡不处理虚空、摔落、烧伤、窒息、魔法、真实、背刺、刺客等伤害。
3. 格挡成功后播放金色粒子和铁砧落地音效，并触发一次 AttackSpeed -50 的冷却。
4. 攻速冷却期间无法触发格挡。
5. 新增 CounterAttack：近战格挡成功后有概率对攻击者造成一次武器基础攻击反击。
6. 弹射物格挡不会触发反击。

五、模板物品
1. test_pct_damage_bow.txt：规模伤害 80%。
2. test_pst_damage_bow.txt：比例伤害 5%。
3. test_attack_range_1_bow.txt：攻击范围 1。
4. test_attack_range_2_crossbow.txt：攻击范围 2。
5. test_parry_counter_weapon.txt：格挡 80%、反击 80%、基础攻击 +5，带方块破碎粒子和凋零受击音效。

六、后续建议
1. 在实服中重点测试快速右键、弩装填、切换物品和攻击后再次拉弓音效。
2. AttackRange 当前设计为复制主目标最终伤害，符合“同样伤害”需求；如果后续要每个目标单独计算护甲，可再拆分配置。
3. 反击当前使用主手武器基础 Attack 值，后续可扩展为完整武器公式。

版本1.6 续写修复记录（二）

一、EXDraw 满阶状态修复
1. 修复拉弓达到最大 EXDraw 阶段后，拉弓循环自动取消导致音效消失的问题。
2. 修复最大阶段时 drawStates 被提前移除，导致发射时 EXDraw 追加伤害丢失的问题。
3. 现在玩家持续拉弓超过最大阶段后，会继续保留拉弓状态，并维持最高阶段音效，直到玩家发射、切换物品、丢弃物品、退出或停止拉弓。
4. 本次没有修改音调计算公式，只修正最大阶段后的状态生命周期。

版本1.6 续写修复记录（三）

一、近战范围与百分比伤害修复
1. 修复 PctDamage 和 PstDamage 只在弓箭/弩弹射物中生效，近战 RPGItem 不生效的问题。
2. 修复 AttackRange 只在弓箭/弩弹射物中生效，近战武器不生效的问题。
3. 近战 AttackRange 现在会以主目标为中心，让范围内其他生物受到同样最终伤害、同样伤害数字，并归属为玩家伤害。
4. 弓箭/弩原有逻辑未做额外改动。

二、打击粒子默认关闭
1. RPGItem 默认打击粒子改为关闭。
2. 只有在单个物品文本中显式写 particles.enabled: true 时才播放打击粒子。

三、发射音效模板
1. 新增 wither_launch_bow.txt，专门用于测试弓箭发射时的凋零头发射音效。
2. 模板内 projectile-trail-sound.enabled: true，sound: ENTITY_WITHER_SHOOT，可绕过旧全局配置验证发射音效。
