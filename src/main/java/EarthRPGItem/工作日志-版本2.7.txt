EarthRPGItem 版本 2.7 工作日志

一、技能触发方式
1. 新增 srskill：玩家蹲下时右键触发。
2. 新增 qskill：玩家按 Q 丢弃键触发。
3. 新增 sqskill：玩家蹲下时按 Q 触发。
4. 特殊技能优先；特殊技能处于冷却时回退到普通 rskill 或 qskill。
5. 右键技能支持主手和副手，副手技能优先选择。
6. 保留已有本地冷却、全局冷却、激活提示、冷却提示和就绪提示。

二、新增技能类型
1. roll：向玩家视线方向施加翻滚位移，支持距离、持续 Tick、无敌 Tick、粒子和音效。
2. range-buffs：按半径、高度、目标类型、持续时间和等级对范围内生物施加药水 Buff。
3. 友好目标默认包括玩家、动物、村民和铁傀儡。
4. 范围 Buff 支持现有粒子配置。

三、技能模板
1. life_recovery_staff.yml：副手范围生命恢复法杖。
2. roll_staff.yml：副手翻滚法杖。
3. 现有范围伤害法杖模板继续保留，可作为亡灵伤害法杖基础。

四、构建与版本
1. 版本号更新为 2.7。
2. Gradle 离线构建成功。
3. 插件包：EarthRPGItem-2.7.jar。
