EarthRPGItem 2.1 工作日志
========================

一、版本目标
------------
本版本补充主动防御体系、反击成长属性、指令技能、防快捷丢弃和 Setting GUI 分页。

二、属性架构
------------
1. RpgItem 与 RpgStats 新增 Dodge、Block、Determination、CAD。
2. 四项属性进入装备、手持和饰品统一聚合流程，并支持 features 全局开关。
3. /rpgitem my 仅在属性有效且数值非零时显示新增属性。
4. Parry 的内部键保持不变，玩家可见术语改为“招架”，保证旧文本兼容。

三、主动防御
------------
1. 新增 ActiveDefenseListener，在普通 RPG 伤害结算前监听玩家受伤。
2. PlayerToggleSneakEvent 只记录进入潜行的时刻，避免持续蹲下被重复识别。
3. 0.3 秒内为成功窗口，0.3 至 0.7 秒为明确失败窗口，窗口均可配置。
4. Block 与 Dodge 同时存在时只使用 Block。
5. Dodge 不调用反击；Block 可调用 CounterAttack，弹射物格挡不反击。
6. 成功后给予抗性提升 III，并根据 Determination 恢复最大生命值百分比。
7. Block 反击和旧 Parry 反击都按 CAD 计算，CAD 不限制百分比上限。

四、物品保护
------------
新增 RpgDropListener。物品栏丢弃动作先记录一次短时许可，随后只放行对应的掉落事件；没有许可的 RPGItem 丢弃事件视为快捷键丢弃并取消。

五、技能扩展
------------
1. FSkillConfig 新增 commands 列表，F/R/L 三种技能共用。
2. as-op: true 使用控制台作为命令发送者，不会修改玩家 OP 状态。
3. @self 与 {player} 在执行前替换为玩家真实游戏名称。

六、GUI 与配置
--------------
1. Setting GUI 改为每页 45 个设置项，底部保留上一页、返回、下一页。
2. 新增 Dodge、Block、Determination、CAD 和快捷丢弃保护按钮。
3. config.yml 新增主动防御窗口、冷却、粒子、音效和音调配置。

七、测试资源
------------
新增四件饰品模板：闪避戒指、格挡手饰、决意项链、反击增伤耳饰。
新增管理员指令技能样本，可验证 @self 替换和控制台权限执行。

八、兼容说明
------------
模板只在目标文件不存在时创建，不覆盖服主已有 RPGItem 文本。
旧 Parry 属性文件无需迁移。2.0 的属性计算方式保持不变。

九、主动防御修正
----------------
1. 新增 1 秒重复按键保护。1 秒内再次按下 Shift 会清除已武装的 0.3 秒窗口，修复连续按键可持续闪避或格挡的问题。
2. 闪避默认音效改为末影人瞬移，并自动迁移旧版默认挥击音效配置。
3. 主动 Block 触发 CounterAttack 后补充物理伤害数字显示。

十、Vitality 与普通物品描述属性
-------------------------------
1. 新增 Vitality 百分比最大生命值属性，公式为 (20 + Health) × (1 + Vitality / 100)，不限制 100% 上限。
2. 新增普通装备英文 Lore 属性解析器，玩家和非玩家生物的盔甲、主手装备均可生效。
3. 普通副手装备沿用 Deputy 限制，避免绕过现有副手设计。
4. 支持 +Attack 5、+Attack: 5、+Attack <5>、+Attack 25% 等格式。
5. 解析前清理 Adventure 样式、&/§ 颜色代码和十六进制颜色代码。
6. 解析器首先排除具有 RPGItem PDC 注册标识的物品，防止 RPGItem 描述产生双倍属性。

十一、普通 Lore 武器近战修正
---------------------------
近战监听旧逻辑只允许注册 RPGItem 进入完整伤害链，普通 Lore 武器虽然完成属性聚合，但会在伤害计算前提前返回。现已增加主手攻击属性检测，带 Attack、MagicDamage、TrueDamage、元素伤害、规模伤害、比例伤害等攻击词条的普通物品会进入完整近战结算。纯防御属性装备不会被误判为武器。

十二、护甲类型隔离修正
----------------------
1. Armor 仅用于物理近战，不再结算 MagicDamage、药水、弹射物和环境伤害。
2. MagicDamage 与药水伤害只进入 EnvArmor、MagicArmor 和 Resistance 防御层。
3. 弹射物物理伤害不再进入 Armor，只进入 EnvArmor、BowArmor 和 Resistance。
4. 元素百分比改为复制护甲结算前的武器与暴击输出，避免 Armor 间接清空元素伤害。
5. 元素最终仍只结算对应元素护甲和 Resistance；TrueDamage 逻辑保持不变。

十三、技能与反击修正
--------------------
1. RPGItem 名称新建时强制关闭斜体，旧物品被识别时同步迁移名称和 Lore 字体。
2. 射线粒子改为强制远距离发送，新增 max-ray-length 默认 512 格和 ray-step 配置。
3. 新增 ChantSkill。吟唱文本按自定义间隔播放，结束后统一释放技能包内全部技能。
4. DamageSkill 新增 damage-type 与 weapon-percent-sources，百分比可读取物理、魔法、弓、真实、元素、规模和比例伤害。
5. 兼容无效旧音效 ENTITY_TNT_EXPLODE，将其映射到 ENTITY_GENERIC_EXPLODE；其他无效名称写入后台警告。
6. 近战、弹射物和技能强制伤害前同时清除 noDamageTicks 与 lastDamage，提升破除无敌帧的稳定性。
7. 主动格挡反击和招架反击均触发武器打击粒子、武器打击音效及劈砍/横扫粒子。
8. 自动修复 id 为 excalibur 的模板中无效音效名称和末尾描述缩进错误。

十四、吟唱阶段与收缩粒子补充
----------------------------
1. ChantSkill 改为阶段模型，每条文本是一个独立阶段，阶段开始时可播放独立粒子和音效。
2. 阶段未配置效果时继承吟唱节点的默认粒子和默认音效，旧版 texts 列表保持兼容。
3. 新增 release-at: start/end/both，可让其他技能在吟唱开始、结束或两个时点释放。
4. 新增动态 contract/收缩粒子：粒子从玩家周围逐 tick 向脚下聚集，动画时长与当前吟唱阶段间隔同步。
5. 第一阶段在第 0 tick 执行，确保吟唱开始音效和粒子立即生效。

十五、技能伤害显示与强制命中补充
--------------------------------
1. 技能百分比伤害来源改为逐类型拆分，物理、魔法、药水、弓、真实和四种元素会分别结算对应护甲并分别显示伤害数字。
2. damage 字段继续使用 damage-type；weapon-percent-sources 中每个来源保持自身伤害类型，不再全部合并成单一元素数字。
3. 新增 POTION_DAMAGE 来源兼容，使用魔法伤害数值并进入 MagicArmor 结算。
4. 近战和技能归属伤害提交后校验实际扣除值；燃烧或其他伤害占用无敌帧时，会补足未成功结算的伤害。
5. 强制伤害前后均清理 noDamageTicks 与 lastDamage，初次伤害事件仍保留玩家作为攻击来源，便于其他插件识别。

十六、木桩虚拟生命与指令目标修复
--------------------------------
1. 木桩最大生命改为虚拟生命机制，配置值写入 PDC，不再受原版实体最大生命属性 2048 等硬上限限制。
2. 木桩名称新增 HP 显示；默认测试值调整为 1000000，DPS 继续按一分钟窗口统计。
3. 近战、弹射物、F/R/L 技能伤害、范围伤害和反击全部接入木桩伤害吸收入口，超高单次伤害只计入 DPS，不会杀死木桩。
4. 木桩受到普通原版伤害时也会取消实际扣血、记录伤害并播放受击动画。
5. give 指令改用统一目标解析器，支持真实玩家名、@self、{player}、<player>、@a、@p 等格式。
6. puton 同步使用统一解析器，并新增 poton 兼容别名；MythicMobs 或代理命令发送者可通过实际实体发送者解析 @self。
7. 指令错误信息拆分为目标错误和 RPGItem ID 错误，避免两种问题共用同一条模糊提示。

十七、吟唱中断、模板生成与 Fix 间隔
------------------------------------
1. ChantSkill 新增 interrupt-on-item-switch，默认 true，可在每个武器的 chants 节点独立修改。
2. 玩家切换主手快捷栏物品时，取消未执行的吟唱阶段、动态收缩粒子和结束释放任务，并清零本次技能冷却。
3. LSkill 吟唱中断时同步清理玩家全局攻速冷却；FSkill/RSkill 则清理对应玩家和物品的独立技能冷却。
4. release-at: start 已释放的效果不做回滚；需要切换物品后技能完全不生效时应配合 release-at: end。
5. 自带测试模板改为按分类目录判断：Armor、Tool、Weapon、Accessory 对应目录完全没有 .txt 配置时才生成该目录的默认模板。
6. 已有任意物品配置的目录不再补写、修复或重新生成自带模板，避免服务器启动时污染服主注册表。
7. Fix 新增 Fix/数字s 格式。Fix/1s:1 每秒恢复 1 点，Fix/5s:1 每五秒恢复 1 点；负数按相同间隔扣除耐久。
8. 旧 Fix/s 保持兼容并固定使用默认 1 秒间隔，例如 Fix/s:2 等同于 Fix/1s:2。

十八、主动格挡视觉修复
----------------------
1. 主动 Block 不再复用 Dodge 的环形粒子布局，修复格挡看起来像闪避的问题。
2. Block 改为玩家视线正前方生成白色盾面粒子，并在中心产生一次闪光；音效继续使用 BLOCK_ANVIL_LAND、默认音调 0.4。
3. Dodge 保留玩家周围的蓝白环形粒子、云雾和 ENTITY_ENDERMAN_TELEPORT 音效，两种主动防御现在拥有完全独立的视觉与声音表现。

十九、YML 多物品与皮革护甲颜色
--------------------------------
1. RPGItem 注册器新增 .yml 和 .yaml 扩展名支持，原有 .txt 单物品配置保持兼容。
2. YML/YAML 可在 items 或 rpgitems 节点下按物品 ID 编写多个独立物品，每个子节点复用完整的现有属性与技能解析链。
3. 多物品节点键作为默认 ID，子节点内显式 id 可覆盖默认值；单物品 YML 不填写 id 时继续使用文件名。
4. 同时兼容没有 items 包装层、直接以多个物品 ID 作为根节点的 YAML，但手册推荐使用 items 结构减少歧义。
5. 文件按名称稳定排序加载，Armor、Tool、Weapon、Accessory GUI 与 give/puton 指令无需修改即可读取多物品注册结果。
6. 默认模板的空目录判断同步识别 .txt、.yml、.yaml，存在任意一种配置文件都不会自动生成模板。
7. RpgItem 新增 leather-color，支持 R,G,B 与 #RRGGBB 两种格式，仅 LeatherArmorMeta 物品应用颜色。
8. 非法皮革颜色会输出后台警告并回退到原版皮革颜色，其他材质自动忽略该字段。
