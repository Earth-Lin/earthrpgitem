EarthRPGItem 工作日志（版本 2.5）

一、采集系统基础实现
--------------------
1. 新增 Items 与 Collection 分类，支持 TXT、YML、YAML 配置。
2. 新增农业、挖掘、伐木采集点，采集点按世界独立保存，支持刷新时间、耗尽方块、掉落物和采集时运。
3. 新增 FarmingSpeed、MiningSpeed、ForestSpeed、FarmingFortune、MiningFortune、ForestFortune 属性。
4. 新增小麦、陨铁矿、橡木采集点及对应测试工具模板。

二、本次问题修复
----------------
1. 修复合法采集点放置被 BlockPlaceEvent 取消的问题。现在创造模式合法放置会正常生成并保存世界独立的采集点，非法支撑方块会取消放置并提示原因。
2. 修复小麦等不可直接触发原版放置事件的资源方块。新增创造模式右键支撑方块的手动放置逻辑。
3. 修复没有采集速度属性时客户端仍显示原版破坏进度的问题。无速度属性时主动向所有在线玩家清除该采集点的破坏动画。
4. `/rpgitem my` 新增六项采集属性统计，并包含饰品栏中已生效的采集属性。
5. 修复技能命令中嵌套 JSON 引号导致命令被提前截断的问题。`command{c="..."}` 现在按外层结束引号解析，可执行烟花等包含 JSON 的原版指令。
6. 农业采集点改为右键启动采集，左键链路完全取消，避免小麦等原版可瞬间破坏的方块掉落原版物品。
7. 加载旧采集点时校正历史错误保存的非资源材质，避免旧小麦点无法正常采集。
8. 采集点周围一格的 BlockPhysicsEvent 现在会取消，采集、耗尽和刷新使用无物理更新方式切换方块。
9. 修复创造模式删除农业采集点时被左键拦截的问题；创造模式现在优先进入采集点删除流程，包含历史已放置的采集点。

三、兼容说明
------------
1. 采集点只在创建它的世界生效。
2. 采集点需要对应采集速度属性才能显示和推进破坏进度。
3. 采集点的方块物理、活塞移动和支撑方块破坏保护继续生效。
