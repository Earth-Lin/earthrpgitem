三、全局冷却结论
RpgItemManager.loadSkill 使用 section.getBoolean("global-cooldown", true)。
因此未填写 global-cooldown 时默认开启；F、R、SR、Q、SQ、L 按触发类型分别计算；未填写 global-cooldown-seconds 时使用 cooldown-seconds；不需要额外注册，在 RPGItem YAML 中配置并执行 /rpgitem reload 即可。
