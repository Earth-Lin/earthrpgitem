EarthRPGItem 版本 2.8 工作日志

一、右键技能链路修复
1. 合并站立右键与蹲下右键为单一入口，按是否蹲下显式分流，修复右键直接触发蹲下技能的问题。
2. 站立右键只触发 RSKILL；蹲下右键优先触发 SRSKILL，SRSKILL 处于冷却时才回退 RSKILL。
3. 增加 200 毫秒右键锁，避免同一次点击因主手与副手事件重复释放。
4. 副手持有可用技能物品时优先作为技能来源。

二、副手支持完善
1. Q 技能与蹲下 Q 技能支持副手来源。
2. 消耗型技能按实际来源手扣除物品。
3. 技能就绪提示同时检查主手与副手。

三、模板与说明
1. 法杖模板整合为单一多物品文件：手动模板/法杖技能合集.yml。
2. 每个法杖补充中文描述，说明副手持有、释放按键、范围与冷却。
3. 新增翻滚核心，含 QSKILL 翻滚与 SQSKILL 蹲下翻滚。
4. 亡灵伤害法杖使用 INSTANT_HEALTH，普通生物被治疗、亡灵受到反伤。

四、构建与版本
1. 版本号更新为 2.8。
2. Gradle 离线构建成功。
3. 插件包：EarthRPGItem-2.8.jar。
